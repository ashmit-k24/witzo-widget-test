How to Get Your Widget Key

1. Call POST /api/auth/widget/create with your config
2. Receive a unique key like wk_abc123…
3. Update any time with PUT /api/auth/widget/update

API Request Example

Use this to create or update your widget configuration:

// Create widget
const response = await fetch('http://localhost:3053/api/auth/widget/create', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer YOUR_JWT_TOKEN', 'Content-Type': 'application/json' },
    body: JSON.stringify({ widgetName: 'My Chat Widget', widgetConfig: { /* ... */ } })
});
const data = await response.json();
console.log('Embed Code:', data.data.embedCode);
